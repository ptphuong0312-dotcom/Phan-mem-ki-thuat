# Quy trình làm việc (Workflow Rules)

**QUY TẮC BẮT BUỘC (CRITICAL):**
Trước khi chạy lệnh thay đổi code hoặc sửa đổi dự án, bạn **BẮT BUỘC PHẢI ĐỌC HẾT TOÀN BỘ NỘI DUNG TRONG THƯ MỤC `.agents`**. 

Điều này bao gồm việc đọc các file `SKILL.md` trong `.agents/skills/` và các file nguyên tắc trong `.agents/rules/` để hiểu rõ bối cảnh, kiến trúc, và các giới hạn giao diện trước khi đưa ra bất kỳ quyết định thay đổi mã nguồn nào.
